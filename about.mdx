## Get up and running

<Steps>
  <Step title="Create a developer account">
    Sign up or log in at [developer.x.com](https://developer.x.com) and apply for developer access. You'll describe your intended use case during the application process.
  </Step>
  <Step title="Get your API keys">
    In the [Developer Portal](https://developer.x.com/portal), create a project and an app. Copy your **API Key**, **API Key Secret**, and **Bearer Token** — you'll need these to authenticate every request.
  </Step>
  <Step title="Make your first request">
    Use your Bearer Token to call the X API v2. Search for recent tweets, look up a user, or pull data from a list — all from the command line or your language of choice.
  </Step>
  <Step title="Build your app">
    Explore the full API reference, grab an official SDK, and use the Postman collection to prototype quickly. Then ship your integration with confidence.
  </Step>
</Steps>
